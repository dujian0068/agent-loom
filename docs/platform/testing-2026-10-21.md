## 发现并修复的问题

| 问题 | 复现与修复 |
| --- | --- |
| 重复工具编号错误去重 | 两条模型消息均使用 `call_0`，要求写两个不同文件，原实现只写了第一个。回执身份现在包含持久化来源消息、调用名称和参数，正常新调用不会被前一次结果替代。相同调用恢复仍复用回执，结果不明的操作仍阻止重放。 |
| 撤权后仍访问 MCP | 队列任务执行前移除成员、停用账号／资源或让期限过期，原实现仍会先创建工作区和访问 MCP。现在装配前检查权限、账号、资源、执行权和期限，并在 MCP 发现前后复查。 |
| MCP 描述随远端漂移 | 远端保持名称与 Schema，只改变工具描述，原实现将新描述交给模型。现在使用发布快照中的固定描述，Schema 变化仍拒绝运行。 |
| 保存回包覆盖新编辑 | 人为延迟保存响应，期间继续修改描述，原实现把新内容覆盖成已提交内容。现在只更新保存版本与基线，保留后续编辑并标为未保存。自动校验不会把这些新编辑算作已校验。 |
| 切换应用／刷新丢草稿 | 同一编辑器路由切换应用未触发离开保护，刷新也无提醒。现在覆盖路由参数变化与浏览器卸载；迟到的加载／保存结果不能覆盖另一个应用。 |
| 漏选模式时提示含糊 | 实际浏览器未选模式提交后，只得到“请求字段不合法”。新增明确的模式校验和 radio 分组，仍由 API 强制必填且禁止后续改模式。 |

运行代码内容摘要随本次修复变化，旧发布不会静默使用新运行逻辑。升级应按当前部署约定先结束旧任务，再重新校验并发布应用。

## 关键测试证据

| 场景 | 实际验证 |
| --- | --- |
| HTTP 模型链路 | 本机 OpenAI 兼容 HTTP 服务接收真实 `ChatOpenAI` 请求，返回结构化计划、工具调用与答案；不是替换 HTTP 客户端。 |
| Plan 中途强杀 | Planner 完成 → Research 写文件并完成 → Writer HTTP 请求阻塞；对真实 Worker 子进程执行 SIGKILL，再启动同一个 Run。恢复后 thread 不变、generation 增加；请求顺序为 `plan, research, research, writer, writer, finish`。规划和研究没有重跑，文件操作回执只有一条；计入被强杀请求后模型调用数为 6。 |
| 错误与额度 | 模型 HTTP 500 不自动重试，不泄露供应商诊断；未授权 Executor 被拒绝；共享模型额度耗尽后不执行后续工具。 |
| 角色资源 | Planner、Research、Writer 得到不同的工具集合；Skill 阅读只允许绑定的固定文件，不向其他角色暴露该技能清单。 |
| MCP | 启动真实 HTTP MCP 服务，发现 `add`／`echo`，只启用 `add`；经过 LangChain 工具调用取得 `2 + 3 = 5`，未选成员不出现在模型工具列表。另测 Schema 漂移、固定描述、发现请求幂等。 |
| SSE 撤权 | 使用真实 Uvicorn 与流式 HTTP，先读取 seq 1，携带 Last-Event-ID 重连；移除成员或过期登录后收到 revoked 并断开，不收到撤权后的测试事件。 |
| 停止与回执 | 模型请求中停止；同步文件线程退出前不能让运行终结或让后续 Run 接管；已有结果复用、未知操作不自动重放、额度拒绝不产生 pending 操作。 |
| 清理与发布 | 注入文件清理 OSError，旧发布保持激活、候选发布等待；清理重试成功才切换。run 工作区删除，session 工作区保留。 |
| 多用户与并发 | 跨空间资源、他人会话及事件不可访问；CSRF、重复键冲突、草稿 If-Match、并发首条消息、发布快照和停止屏障保持有效。 |
| 前端异步竞态 | 保存期间继续编辑；自动保存期间再编辑；慢响应跨路由返回；取消离开保留草稿；刷新提醒；丢响应重试保持同一幂等键、正文、CSRF、revision；409 不自动重试。 |

浏览器验收另外覆盖创建时名称／描述／模式、模型连接选择、环境设置、只读工作区与写工具冲突提示、Tool／Skill 固定版本、资源独立管理入口、保存校验发布、会话运行及刷新持久化。页面不会把尚未接入的沙箱、脚本或外部集成显示为可用。

## 尚未证明的范围

- 本轮模型 HTTP 服务是可控测试服务，没有调用真实供应商或消耗真实模型额度；真实供应商的模型差异、限流和网络异常仍需联调。
- 测试覆盖一个明确的中途强杀切点，不代表每个数据库提交／检查点提交边界都已故障注入，也不证明远端非幂等副作用“恰好一次”。
- 尚无生产负载、长时间稳定性、跨主机接管、升级迁移、备份恢复、完整删除生命周期验收。
- 沙箱和未接入的外部工具仍不可用。完整功能边界见[当前实现](implementation.md)，完整目标见[验收计划](verification.md)。
