# 平台验收计划

更新：2026-10-20。本页为 LangChain + LangGraph 平台待实施验收，不是已通过报告。现有交互原型和 agentloom-sdk 测试都不能作为平台运行验收。

| 场景 | 必须断言 |
| --- | --- |
| 前后端分离 | Web 无 Python 可构建，后端无 Node／前端产物可启动；Web 重启不终止 Run |
| 身份与空间 | 成员权限及私有会话分别检查；无权请求不创建输入、任务或资源调用 |
| 创建与模式 | 同表单名称、描述、必选 ReAct／Plan；缺模式拒绝，创建后不可修改 |
| 资源管理 | 独立 Tool／Skill／MCP 页可添加、就绪、固定版本再绑定；未就绪版本不可发布 |
| 角色授权 | Planner 与每个 Executor 只取得自己的工具、Skill 和 MCP 成员；猜测工具名也不能绕过授权 |
| Skill | 基础 profile、逐步读取、只读挂载；未支持扩展明确拒绝；脚本不自动获得 exec |
| MCP | 固定成员、Schema、版本；连接或发现漂移不自动授予新工具；多服务分别授权 |
| 沙箱与工作区 | 只读权限实际生效；文件工具和脚本视图一致；关闭沙箱阻止 exec；保留文件独立于进程 |
| 独立运行底座 | 平台不导入 agentloom；ReAct 为 LangChain Agent，Plan 为实际 LangGraph 编排 |
| 发布快照 | 恢复使用原图、状态格式、资源、镜像和策略；下一次新提问使用当前发布 |
| 单写者 | 同 Session 一个活动／预留 Run；同 thread 不并发推进；旧 owner 未撤销时不接管 |
| HTTP 幂等 | 同键／client_message_id 同正文返回原身份；不同正文冲突，不重复用户消息 |
| 接入崩溃 | 平台已保存、图尚未接入时重投原输入；图接入后回执丢失时从检查点对账 |
| 终态崩溃 | 图完成后、平台终态前崩溃，仅补结果和事件，不重新调用模型／工具 |
| 子图恢复 | 活动 Executor 继续原任务和命名空间，不靠 Planner 重新规划冒充恢复 |
| 补充竞态 | 输入被采用或转 pending_next_run，稳定 ID 不丢不重；不自动开下一轮 |
| Plan 补充 | 只进入 Planner 下一次决策，不广播 Executor 或修改变量快照 |
| 停止 | API 保存意图；独立控制入口收束；远端结果不明不能立即显示已停止；用户无恢复按钮 |
| 发布屏障 | 包含预留 Run；旧 Worker 迟到不得出网或新建执行域；候选版本不被后续草稿修改 |
| 外部副作用 | 目标支持幂等则复用原键；未知非幂等操作进入诊断，不盲目重放 |
| SSE | 持久序号、去重和续读；断线不停止 Run，撤权后不继续推送 |
| 删除 | 先撤销写者，再清理指定 thread、子图、输入和专属文件；共享资源和墓碑保留 |
| 备份与升级 | 同一静止状态可重建；不兼容图／库版本明确阻止恢复，不静默降级 |
| 真实联调 | 通过 HTTP 运行 ReAct、Plan、Tool、Skill、MCP；沙箱执行单独验证 |

测试报告记录依赖与镜像版本、请求和回执、run_id／graph_thread_id、故障切点、检查点证据、事件、文件及外部调用次数。确定性模型、真实存储进程故障、真实供应商分别标记。

P0 必须先证明输入接入与采用回执、恢复单写者、Plan 子图、停止和 checkpointer 清理这些合同，再承诺对应交互可用。文档构建和原型点击测试不算上述运行测试通过。
