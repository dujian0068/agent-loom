# SDK 独立示例验收

当前仅记录目标，没有可运行示例。实现后每个示例必须能在不安装 Platform、不登录、不查询平台发布记录的空白 Python 项目中运行。

| 示例 | 最小执行路径 | 验收点 |
| --- | --- | --- |
| ReAct | 模型 → 工具 → 模型 → 最终回答 | 工具结果进入同一角色上下文；业务 Loop、Hook 和结束语义正确 |
| Plan–Executor | Planner → 同类型 Executor 的两次委派 → 汇合 → Planner | 上下文独立、工作文件按授权共享；用户配置决定串并行；失败结果与成功结果一同汇合 |
| Workflow | 普通节点／能力节点 → AgentNode → 后继节点 | 状态映射、路由和结果正确；外层关联原 Agent 调用，恢复不另起独立 ExecutionRecord |

确定性模型适配器用于验证流转，真实模型配置通过调用者注入。两类测试分别报告，不将模拟输出算作真实模型验收。

另设故障测试：一个 Executor 已完成、另一个执行中时销毁当前进程，在新进程用相同配置、ExecutionRecord 标识与持久存储恢复；验证不重做已保存的结果、不重置预算、不重复添加输入。

内存存储仅用于进程内演示，不能用它证明跨进程或跨机器恢复。
